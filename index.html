Path color picker

Extract colors by drawing any path across an image with your cursor.

Supports

  • + RGB, sRGB, HEX, OKLCH, OKLAB, HSL, XYZ D65, XYZ D50, LCH, LAB
  • + path sampling
  • + panning and zooming
  • + adjustable sampling frequency
